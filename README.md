# tex2sto

`tex2sto` — проект конвертера документов на ограниченном диалекте LaTeX в
редактируемый Word-файл и, при необходимости, PDF. Оба результата должны
соответствовать требованиям СТО Самарского университета, при этом DOCX является
приоритетным форматом.

Проект находится на этапе проектирования. Сейчас в репозитории подготовлен
инженерный harness, но исполняемого CLI и поддерживаемого пользовательского
диалекта ещё нет.

Планируемый интерфейс:

```text
tex2sto build document.tex
tex2sto build document.tex -o output --pdf
```

Первая команда должна создавать DOCX. Флаг `--pdf` будет дополнительно включать
сборку PDF. Приведённые команды фиксируют согласованный интерфейс, но пока не
реализованы.

Пользовательская документация будет находиться в [`docs/`](docs/README.md).
Инженерные решения и контекст для разработки находятся в `harness/` и не нужны
для обычного использования программы.
