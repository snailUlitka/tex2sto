# tex2sto

`tex2sto` компилирует документ на контролируемом диалекте LaTeX в
редактируемый DOCX по СТО 02068410-004-2018 Самарского университета. По флагу
`--pdf` программа дополнительно строит независимый PDF. Произвольный LaTeX не
поддерживается: неизвестные команды и неоднозначная структура считаются
ошибками.

Проект находится на стадии `0.1.0` (alpha), не является официальным продуктом
Самарского университета и не заменяет проверку документа по действующему СТО.

## Быстрый старт

Требуются Python 3.12.11, uv 0.12.x, Pandoc 3.11 и TeX Live 2026. После
установки внешних инструментов:

```sh
uv sync
uv run tex2sto check examples/master-thesis/main.tex --strict
uv run tex2sto build examples/master-thesis/main.tex -o build/example --pdf
```

Без `--pdf` создаётся только DOCX. Если `-o` не задан, результат помещается в
каталог `build` рядом с главным `.tex`-файлом.

Воспроизводимый вариант через Docker:

```sh
docker build -t tex2sto:0.1.0 .
docker run --rm -v "$PWD:/work" tex2sto:0.1.0 \
  build examples/master-thesis/main.tex -o build/example --pdf
```

Полная документация:

- [установка](docs/installation.md);
- [командная строка](docs/cli.md);
- [поддерживаемый диалект](docs/dialect.md);
- [разбор полного примера](docs/example.md).

Программа проверяет формальные и механически определимые требования. Она не
оценивает научную новизну, смысл, терминологию и качество академического текста.
Исходный СТО остаётся нормативным документом.
