# tex2sto

`tex2sto` компилирует документ на контролируемом диалекте LaTeX в
редактируемый DOCX по СТО 02068410-004-2018 Самарского университета.
Произвольный LaTeX не поддерживается: неизвестные команды и неоднозначная
структура считаются ошибками.

Текущая стабильная версия — `2.0.0`. Проект не является официальным продуктом
Самарского университета и не заменяет проверку документа по действующему СТО.

## Быстрый старт

Требуются Python 3.12.11, uv 0.12.x и Pandoc 3.11. После установки внешних
инструментов:

```sh
uv sync
uv run tex2sto check examples/master-thesis/main.tex --strict
uv run tex2sto build examples/master-thesis/main.tex -o build/example
```

Настройки проекта задаются в необязательном `tex2sto.toml` рядом с главным
`.tex`-файлом. Пустой конфиг использует значения по умолчанию. Если `-o` и
`build.output_dir` не заданы, DOCX помещается в каталог `build` рядом с исходником. Флаг `--pdf` пока создаёт экспериментальный предварительный PDF,
который не входит в гарантии совместимости версии 2.0.

Воспроизводимый вариант через Docker:

```sh
docker build -t tex2sto:2.0.0 .
docker run --rm -v "$PWD:/work" tex2sto:2.0.0 \
  build examples/master-thesis/main.tex -o build/example
```

Для лабораторных доступен [короткий пример](examples/lab-report/main.tex):
одна команда `\labtitle{...}` в начале `.tex` задаёт номер работы, курс, автора,
группу, проверяющего и год. Вариант и подписи участников можно уточнить
необязательными параметрами. Сборка:

```sh
uv run tex2sto build examples/lab-report/main.tex -o build/lab-report
```

Для отчёта по практике есть [отдельный пример](examples/practice-report/main.tex)
с титульником, заданием и таблицей компетенций. Его локальный конфиг выбирает
положение сокращений после заключения и одинарный интервал таблиц.
В версии 2.0 исправлены отступы заголовков и ключевых слов, переносы перечней,
пояснения формул и границы частей таблиц. Разделители по умолчанию используют
дефис; длинное тире разрешается настройкой.

После рендера можно проверить настроенные границы числа страниц командой
`tex2sto check-pages main.tex rendered.pdf`. По умолчанию границ нет.

Программа проверяет формальные и механически определимые требования. Она не
оценивает научную новизну, смысл, терминологию и качество академического текста.
Исходный СТО остаётся нормативным документом.
