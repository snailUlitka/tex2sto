# Участие в разработке tex2sto

Спасибо за интерес к проекту. Перед началом работы проверьте, что предложение
соответствует [целям и ограничениям V1](harness/product.md). Проект принимает
только документированный диалект tex2sto и не стремится поддерживать
произвольный LaTeX.

## Подготовка окружения

Требования и установка описаны в [пользовательской документации](docs/installation.md).
Для разработки из корня репозитория выполните:

```sh
uv sync
```

## Изменения

- Обсудите крупное изменение или расширение диалекта в GitHub Issues до
  реализации.
- Добавляйте положительные и отрицательные тесты для новых конструкций
  диалекта.
- Обновляйте русскоязычную документацию при изменении поведения пользователя.
- Обновляйте документы в `harness/` при изменении архитектуры, инвариантов,
  стратегии проверки или плана работ.
- Не добавляйте в репозиторий исходный текст СТО, лицензированные шрифты,
  локальные шаблоны или документы с персональными данными.

## Проверка

Минимальный набор перед pull request:

```sh
uv run ruff check .
uv run pytest
uv run tex2sto check examples/master-thesis/main.tex --strict
uv build
git diff --check
```

Изменения рендереров дополнительно требуют структурной и визуальной проверки
DOCX и PDF согласно [стратегии валидации](harness/validation.md).

## Уязвимости

Не публикуйте сведения об уязвимости в открытом issue. Используйте порядок из
[SECURITY.md](SECURITY.md).
