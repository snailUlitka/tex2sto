# История изменений

## 2.0.0

Добавлены настройки проекта и отчёт по практике с отдельным титульником и
редактируемым заданием по компетенциям. DOCX остаётся основным выходным
форматом; PDF сохраняет статус экспериментального предварительного просмотра.

### Новые возможности

- Необязательный `tex2sto.toml`: пустой файл использует значения по умолчанию.
  Настройки общие для CLI и MCP; явные параметры имеют приоритет над TOML.
- Локальный выбор положения определений и сокращений, интервала таблиц,
  разделителей, маркеров и нумерации перечней.
- Команды `practicetitle` и `practiceassignment` для титульника практики,
  реквизитов приказа, дат и таблицы компетенций.
- Команда `check-pages` и MCP-инструмент `check_pages` для предупреждений по
  минимальному и максимальному числу страниц уже отрендеренного PDF.
  По умолчанию ограничений нет. Для проверки используется Poppler `pdfinfo`;
  LibreOffice не требуется для сборки.
- Справка по настройкам в MCP-ресурсе `tex2sto://configuration/v2`.

### Исправления

- Отступ первой строки 1,25 см у нумерованных заголовков и ключевых слов.
- Продолжение строк перечня от левого поля.
- Проверка первой ссылки перед нумерованной формулой, пояснения после
  ненумерованных формул, точки с запятой между пояснениями и интервалы формул.
- Ненумерованные формулы не расходуют номера последующих формул.
- Отсутствующая нижняя граница у прерванных частей многостраничной таблицы.
- Начало разделов с новой страницы независимо от пустых строк в исходнике.
- Сохранение дефисов в обозначениях стандартов при оформлении библиографии.

### Переход с 1.x

- По умолчанию в создаваемых подписях, определениях, пояснениях и библиографии
  используется дефис. Диапазоны используют короткое тире. Длинное тире и
  LaTeX-запись `---` в авторском тексте вызывают `T2S-W106`, который блокирует
  строгую проверку. Для местных требований длинное тире можно разрешить
  через `punctuation.allow_em_dash = true` и выбрать `separator = "em-dash"`.
- Интервал таблиц остаётся 1,5; одинарный задаётся явно.
- Сокращения по умолчанию остаются до введения. Для размещения после
  заключения задайте `structure.terminology_position = "after-conclusion"`
  и перенесите блок в исходнике.
- Ссылки на нумерованные формулы нужно размещать перед ними. Ненумерованная
  формула не должна объявлять метку; для ссылочной используйте `equation`
  или `align`.
- MCP-ресурс диалекта теперь имеет URI `tex2sto://dialect/v2`.
- Источники без цитат по-прежнему остаются в списке с предупреждением.
  Полного поля Word TOC, страниц цитирования, альбомных страниц и проверки
  возраста источников в этом выпуске нет.

Полный список параметров и пример локальных правил:
[настройки проекта](docs/configuration.md).
