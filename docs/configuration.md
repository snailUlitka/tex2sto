# Настройки проекта

Файл `tex2sto.toml` рядом с главным `.tex` задаёт настройки проекта. Файл можно
не создавать или оставить пустым: используются значения по умолчанию.
Для другого пути передайте `--config путь.toml` в `check`, `build` или
`check-pages`; в MCP используется параметр `config`.

Приоритет: значения по умолчанию, затем TOML, затем явно заданные параметры
CLI или MCP. Неизвестные ключи, неверные типы и противоречивые значения
вызывают ошибку. Метаданные и текст документа задаются в `.tex`.

Полный перечень настроек со значениями по умолчанию:

```toml
[build]
output_dir = "build"
pdf = false
strict = false

[numbering]
mode = "auto"
threshold = 10
# figure = "auto"   # по умолчанию наследует mode
# table = "auto"
# equation = "auto"

[layout]
table_line_spacing = 1.5

[structure]
terminology_position = "before-introduction"

[punctuation]
separator = "hyphen"
allow_em_dash = false

[lists]
marker = "hyphen"
numbering = "hierarchical"

[pages]
# minimum = 25      # по умолчанию нижней границы нет
# maximum = 100     # по умолчанию верхней границы нет
```

Относительный `build.output_dir` разрешается от каталога главного `.tex`,
в том числе при явном `--config`. Явный CLI `-o` разрешается от текущего
рабочего каталога. `--no-strict` и `--no-pdf` отключают включённые в TOML флаги.

Режимы нумерации: `auto`, `global`, `section`; порог — положительное целое число.
Интервал таблиц — число от 1 до 3. `terminology_position` допускает
`before-introduction` и `after-conclusion`: определения и сокращения размещают
в исходнике в выбранном месте; после заключения они должны предшествовать
источникам и приложениям.

Разделитель `separator` равен `hyphen`, `en-dash` или `em-dash`. Он применяется
к подписям, определениям, пояснениям формул и библиографии. Числовые диапазоны
используют короткое тире. Для `em-dash` обязательно `allow_em_dash = true`.
Разрешение длинного тире отключает предупреждение `T2S-W106` в авторском тексте.
Текст программы в `verbatim` не проверяется этим правилом.

Маркер перечня — `hyphen`, `en-dash` либо `em-dash` (последний требует
`allow_em_dash = true`). Режим `hierarchical` сохраняет
кириллические буквы на вложенных уровнях нумерованного перечня; `decimal`
использует арабские цифры на всех уровнях.

Пример локальных правил отчёта по практике:

```toml
[layout]
table_line_spacing = 1.0
[structure]
terminology_position = "after-conclusion"
[lists]
numbering = "decimal"
[pages]
minimum = 25
```

Лимиты страниц проверяются после фактического рендера отдельной командой:

```sh
tex2sto check-pages main.tex rendered.pdf
tex2sto check-pages main.tex rendered.pdf --strict
```

Команда использует `pdfinfo` из Poppler, считает все страницы переданного PDF
и выдаёт `T2S-W601` или `T2S-W602`. На границах предупреждения нет. Без `--strict`
нарушение границ остаётся предупреждением. Для контроля только описательной
части передайте отдельный PDF с этой частью. Соответствие PDF актуальной
версии исходника обеспечивает автор. Команда сама не рендерит DOCX, не меняет
его и не делает LibreOffice обязательным инструментом сборки.
