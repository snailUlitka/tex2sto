# Полный пример

Для лабораторной работы есть короткий пример
[`examples/lab-report/main.tex`](../examples/lab-report/main.tex). Титульник
задаётся одной командой `\labtitle{...}` в начале файла; параметры описаны в
[диалекте](dialect.md#лабораторная-работа). Пример содержит вариант лабораторной
и подпись «Проверила», но оба параметра можно опустить.

```sh
uv run tex2sto check examples/lab-report/main.tex --strict
uv run tex2sto build examples/lab-report/main.tex -o build/lab-report
```

Результат — `build/lab-report/main.docx`: титульный лист и основной текст без
реферата, содержания и задания ВКР. Нумерованные разделы, как и в полном
примере ниже, начинаются с новых страниц.

Каталог [`examples/master-thesis`](../examples/master-thesis/) покрывает полный
маршрут V1: титульный лист, двухстраничное задание, реферат, содержание,
определения, сокращения, введение, разделы, вложенные перечни, рисунок, формулу,
обычную и многостраничную таблицы, источники и приложение с кодом.

Проверка и сборка из корня репозитория:

```sh
uv run tex2sto check examples/master-thesis/main.tex --strict
uv run tex2sto build examples/master-thesis/main.tex -o build/example
```

Будут созданы:

```text
build/example/main.docx
```

Экспериментальный предварительный PDF можно дополнительно запросить флагом
`--pdf`, но он не входит в гарантии совместимости версии 1.0.

Чтобы начать свой документ, скопируйте каталог примера, замените метаданные и
текст, но сохраняйте семантические команды. Не копируйте прямое форматирование
из Word или произвольные LaTeX-пакеты: размеры, стили, подписи и нумерацию
назначает профиль.

Большую работу можно разбить на файлы внутри одного каталога:

```tex
\begin{document}
\input{chapters/introduction}
\input{chapters/main}
\input{chapters/conclusion}
\end{document}
```

Главным остаётся файл с `\documentclass`, метаданными и окружением `document`.
Пути `\input` не могут выходить из его каталога.

После сборки откройте DOCX в Microsoft Word, разрешите обновление полей и
проверьте персональные данные титульного листа и задания. Автоматическая
проверка не заменяет содержательную вычитку и сверку с действующим СТО.
