# Пользовательская документация tex2sto

`tex2sto` принимает только описанный здесь диалект и создаёт редактируемый DOCX
по профилю Самарского университета. Экспериментальный PDF можно запросить
отдельно, но он не входит в гарантии совместимости версии 1.0.

- [Установка](installation.md) — нативный macOS и Docker.
- [Командная строка](cli.md) — проверка, сборка, нумерация и коды завершения.
- [Диалект](dialect.md) — полный перечень команд, окружений и ограничений V1.
- [Полный пример](example.md) — структура проекта и готовые команды.

Диагностика программы написана на английском, чтобы сообщения оставались
одинаковыми в CLI, тестах и журналах сборки. Пользовательский исходник и
документ могут быть написаны по-русски.
