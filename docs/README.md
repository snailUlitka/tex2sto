# Пользовательская документация tex2sto

Этот каталог предназначен только для русскоязычной пользовательской
документации: установки, командной строки, поддерживаемого диалекта LaTeX и
примеров документов.

Проект пока находится на этапе проектирования, поэтому исполняемой программы и
стабильного диалекта ещё нет. Документы об установке, CLI, диалекте и примерах
будут добавляться одновременно с соответствующей реализацией и проверяться по
реальным командам. До этого момента единственной пользовательской точкой входа
является [корневой README](../README.md).

Материалы для агентов и разработчиков намеренно вынесены в `harness/` и ведутся
на английском языке.
